# Putting AI Bridge on your phone (about 5 minutes)
1. Get the file `app-debug.apk` onto the phone (for example, download it from a private link you are sent).
2. Tap the downloaded file. If Android says installing unknown apps is blocked, tap **Settings**, turn on **Allow from this source** for that app (for example, Chrome or Files), then go back.
3. If Play Protect shows "App scan recommended", tap **Scan app**, then **Install** if it says the app looks safe.
4. Open **AI Bridge**. You will see a red **STOP RELAY** button at the top. Tap it at any time to halt everything. Tap again to resume.
5. Make sure the ChatGPT and Grok apps are installed and you are already signed in to them. The bridge never asks for passwords.
6. Use only made-up test messages at first (for example, "Synthetic test: reply with the word banana").
To remove it: long-press the AI Bridge icon → App info → Uninstall.
